# Server Configuration

The server configuration is stored in:

config/server.conf

## Parameters

SERVER_NAME
Defines the name of the Linux server.

ENVIRONMENT
Defines the server environment. The current environment is development.

LOG_LEVEL
Defines the level of logging.

BACKUP_ENABLED
Controls whether backups are enabled.

MAX_CONNECTIONS
Defines the maximum number of allowed connections.

## Configuration Changes

Configuration changes should be tested in a separate Git branch before they are merged into the main branch.
