# Installation Guide

## Requirements

The following software is required:

- Ubuntu Linux
- Git
- Bash

## Installation

Clone the repository:

git clone https://github.com/Bekhan9/linux-devops-project.git

Open the project directory:

cd linux-devops-project

Make the system information script executable:

chmod +x scripts/system_info.sh

Run the script:

./scripts/system_info.sh

## Verification

Check the Git repository:

git status
